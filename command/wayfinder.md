Chart a wayfinder map for: $ARGUMENTS

Follow the wayfinder skill:

1. Confirm the destination with the user (one sentence).
2. Identify the first few tickets at the frontier of what you know.
3. Create the map as `docs/learning/wayfinder-<topic>.md` via `project-log`:
   - Destination
   - Notes
   - Decisions so far (empty to start)
   - Tickets (list with status: pending/done)
4. Resolve the first ticket (usually a decision ticket — research + user choice).
5. Report what opened up: new tickets, new fog.

Rules: Never resolve more than one ticket per session. The map is deliberately incomplete — tickets emerge from fog as you go. If you get lost, stop and re-chart with the user.
