Run the graduation session.

Instructions:

1. Load the `mentor-graduation` skill and follow its workflow.
2. Confirm the trigger: goal-reached or chosen end. If the learner is
   discouraged, do NOT graduate — run `mentor-motivation` and re-scope
   instead.
3. Final assessment: full mastery snapshot from `mastery.md`, roadmap
   milestone status, completed challenges, top 3 prouds.
4. Exit interview (5 questions): what worked, what didn't, what the mentor
   should change for future learners, what they still want to learn alone,
   what they'd change about mentor mode.
5. Write `docs/learning/mentor/graduation.md`: snapshot + answers + a
   "without-me plan" (self-directed next steps, 3-month review schedule,
   condition-based return trigger).
6. Cross-project rollup: `memory-log` → `memory/mentor/rollup.md` (project,
   dates, top skills mastered, notable wins).
7. Archive profile/roadmap rows ("archived <date>") and close with a sincere
   evidence-based message: what they proved, and what comes next.

If this is an ALUMNI return instead: load `graduation.md` + the rollup,
greet with where they left off, and resume with a light re-intake.
