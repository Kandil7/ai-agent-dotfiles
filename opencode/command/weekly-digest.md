Build the weekly learning digest.

Instructions:

1. Load the `weekly-digest` skill and follow its workflow.
2. Gather the week: scan `docs/learning/sessions/` for the last 7 days,
   `docs/learning/diffs/`, `docs/learning/curricula/`, the mentor diary
   (`mentor/diary.md`), and any check-ins.
3. Write the digest via `learning-log` →
   `sessions/digest-<YYYY-Www>.md` (ISO week, e.g. `digest-2026-W32.md`):
   - Week summary: sessions count, hours estimate, wins
   - Patterns: what repeated across sessions (good and bad)
   - Open threads: topics still fuzzy or unfinished
   - Next week focus: 2-3 items (align with the mentor roadmap if it exists)
4. Update `00-INDEX.md` (add the digest to the index).
5. Reply with a 5-line summary: wins, patterns, open threads, next focus.
   If a mentor check-in is due, note that `/mentor-checkin` can consume this
   digest directly.

Tone: honest consolidation — the digest is for the learner's own memory, not
for praise.
