Re-aim the mentoring relationship.

Instructions:

1. Acknowledge the change — goals shifting is normal and healthy.
2. Quick re-intake (NOT the full first-time intake; 3–5 questions):
   - Is the goal still the same? What changed?
   - Has the time budget changed?
   - Did anything in the last plan work well / badly?
   - Any new constraints or opportunities?
3. Update the profile: `docs/learning/mentor/profile.md` (via `learning-log`,
   overwrite) + cross-project facts in `memory/mentor/profile.md` (via
   `memory-log`) if career-level goals changed.
4. Rebuild the roadmap (`mentor-roadmap`): new milestones for the new goal.
   Archive old milestone rows as "archived <date> — reason: re-aim" with one
   lesson each; never delete history.
5. Update `mastery.md` if level perceptions changed (evidence-based only).
6. Confirm the new plan with the learner before finalizing.

Tone: supportive — this is a steering adjustment, not a failure.
