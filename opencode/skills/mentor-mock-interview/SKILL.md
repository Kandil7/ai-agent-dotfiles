# Skill: mentor-mock-interview

## Purpose

Knowledge under pressure is different from knowledge in chat. The mock
interview builds **performance**: answering clearly, handling follow-ups,
admitting gaps without crumbling — scored and logged so each round beats the
last.

---

## When to Use

Use this skill when:

- The learner's goal includes interviews (from the profile).
- The learner says "دربني على المقابلات" / "mock interview me".
- A roadmap milestone is interview prep (often the final milestone).

---

## Step-by-Step Workflow

1. **Setup** (30 seconds, not a lecture):
   - Target role (from profile goals; ask if unknown).
   - Duration (default 30 min) and topic mix (e.g. 4 technical + 2 behavioral).
   - Rules: mentor asks ONE question at a time; no hints during the answer
     (clarifying questions allowed); timing per question.
2. **Run the interview**:
   - Ask question → learner answers → 1 follow-up max per question.
   - Silently score each answer: **structure** (clear start/end), **accuracy**,
     **depth** (why, trade-offs, edge cases), **communication** (concise,
     confident) — 1–5 each.
   - Note strengths and the single biggest miss per question.
3. **Feedback round** (after all questions):
   - Strengths first, honestly; then gaps; then one model answer per weak
     question — linked to the repo's real code (`walkthroughs/`,
     `architecture.md`, `decisions/`) so the answer is grounded, not generic.
   - Verbalize the score: "You scored 3.5/5 average; structure is your
     strength, depth under follow-up is your gap."
4. **Log** — `learning-log` → `mentor/mock-interviews.md` (append):
   - date, role, questions asked, per-question scores, total/average,
     strengths, gaps, model-answer links, next round's focus.
5. **Update ledgers** — `mastery.md` evidence (interview answers prove
   Proficient-level communication); roadmap (mark interview milestone progress).
6. **Next round** — schedule a follow-up (default +1 week) and name the ONE
   thing to improve before it.

---

## Notes

- Kind but honest scoring: inflated scores help no one at the real interview.
- Behavioral questions: coach STAR (Situation-Task-Action-Result) structure.
- If the learner freezes, pause the clock, debrief the freeze briefly
  (confidence gap → small win), and continue — real interviews don't stop,
  but this is practice.
